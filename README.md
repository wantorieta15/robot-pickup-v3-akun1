## Entry

72 characters, one line, UTF-8.

## How it works

`main.py` (pure Python stdlib, no network) writes the entry line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating
that it is a single line of 1–120 characters.
